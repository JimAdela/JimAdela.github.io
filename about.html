天涯无岁月 歧路有风尘
百年浑似醉 是非一片云

Hey，我是无意（WY），后端工程师，在合肥。白天写 Laravel 与 PostgreSQL——支付、分区、幂等这些不能出错的东西；晚上读论文，把式子推到能跑出数字为止。

笔记分三条线。AI 数学直觉的标准是能闭着眼睛推出那个式子，工程实战的标准是能照着敲下去不出错，开源大模型源码精读的标准是每个行号都对得上、每个张量形状都能跑出来。中间那些「五分钟上手」「一文读懂」的东西，这里不写。

站点用 GitHub Pages 与 Jekyll 搭建，源码在 GitHub。有问题欢迎提 issue 或邮件。
